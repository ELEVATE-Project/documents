# Overview

A program designer can create programs for different entities using the program templates. 




You can access programs using the Programs tile on the Home page.

![](media/homepage.png)

Select the Program tile to view the programs mapped to your role and location. The Programs page appears as shown in the following figure.

![](media/programs.png)

A program contains the following resources:

* **Improvement Projects**
* **Observations** 
* **Surveys**

End users can consume these resources through programs. Projects can be embedded in a capacity-building program undertaken by organizations and institutions.


## Accessing Projects through Programs

You can access projects using the Programs tile on the Home page.
Projects can be embedded in a capacity-building program undertaken by organizations and institutions.


To access projects, do the following:

1. Click the **Programs** tile to view the programs mapped to your role and location.

2. From the list of programs, select a program of your choice to view the projects listed under it.

3. On the Project page, click the project that you want to start working on.
