By default, the dashboard displays the mentoring session details for a mentee. You need to change the role to mentor.  To change to mentor, select the Mentor role from the **Role** dropdown.

![](media/changeroletomentor.png)


The dashboard provides a summary of the following:

1. Total number of public and private sessions created and conducted by the mentor.
2. Total hours taken to conduct public sessions and private sessions.
3. The bar graph gives a quick comparison of the number of sessions created or assigned and the number of sessions conducted.

## Mentoring Session details

You can view the mentoring session details, such as who created the session, how many mentees attended the session, the date on which the session was conducted, the session type, (such as public or private),
 and the duration of the session.


From this section you can perform the following actions:

1. **Sort**: Sort the table data  in ascending or descending order using the ![](media/sorticon.png)icon

2. **Search**: Search for the session details either by entering a keyword in the search box provided or by selecting the relevant values in the select boxes provided. For example, to search for the number of mentees who have attended a session, select a value 
from the **Number of Mentees** dropdown.

![](media/mentorsessiondetails.png)

3. **Filter**: **Clear Filters** option appears only after you enter a search criteria in the search boxes provided. 
           To clear the filter applied, click **Clear Filters**.

4. **Download Table**: Click **Download table** to download the table data as a CSV file. 


## Download Table

**To download the table data, do as follows**:

1. Click **Download Table**. A pop up window appears that allows you to select the time period.

![](media/selectdaterange.png)

2. Select the start date and the end date using the calendar icon.

3. Click **Submit** to download the data as a CSV file.
