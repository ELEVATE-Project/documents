# Responding to Requests

The Request section allows you to view the session requests and manage the message requests that you have received from 
the mentees or mentors.

To view the session requests and the message requests, do as follows:

1. Select **Requests** from the left panel. The Request page appears.

2. There are two tabs: (1) **Session requests** (2) **Message requests**

## Viewing Session Requests

On the **Session requests** tab, you can view the **Request sessions** details. 

  ![](media/mentorsessionrequest.png)

To view the session details, click **View details**


## Managing Message Requests

This tab refers to the message requests that you have received, but have not yet accepted.

 ![](media/mentormessagerequest.png)



## Accept or Reject Message Request

After you receive a chat request from a mentee or mentor, you can accept or reject the request.

**To accept or reject a request, do as follows:**

1. Select the **Message requests** tab.

2. Click **View Message**. The message request page appears.

    ![](media/acceptorreject.png)

3. Do one of the following:

    * Click **Accept** to accept the request. A message appears stating that you have accepted the request and the mentee is added to your connections.

    * Click **Reject** to reject the request. A message appears to confirm whether you want to reject this message request.

      Click **Reject** to reject the message request or **Cancel** to return to the message request page.
