# Hosting and Customizing Reports

The Report capability is enabled by the data collected through other Elevate capabilities, such as Projects, Mentor, Observations, and Surveys.
This can be set up in any cloud environment or in an on-premise setup.

To host a customized instance of Reports, refer to the README section of the following link:
