# Key Capabilities of Reports

<table>
<tr>
    <th>Features</th>
    <th>Description</th>
</tr>
<tr>
    <td>Real-Time Data Processing</td>
    <td>
    <ul>
    <li>Submissions are processed via Flink jobs for all the real time Kafka events and stored in PostgreSQL.
    </li>
    <li>Enables real-time dashboard updates.</li>
    </ul>
    </td>
</tr>

<tr>
    <td>Default Dashboards</td>
    <td>
    <ul>
    <li>Pre-configured dashboards for specific roles. For example: program managers, state and district level admins.
    </li>
    <li>Includes Program and Admin dashboards with drill down at state, district, block and cluster level.</li>
    </ul>
    </td>
</tr>

<tr>
    <td>Downloadable Reports</td>
    <td>
    <ul>
    <li>Reports are available in CSV and PDF formats.
    </li>
    <li>No need to wait 24 hours for data refresh, unlike in Diksha.</li>
    </ul>
    </td>
</tr>

<tr>
    <td>Role-based access</td>
    <td>
    <ul>
    <li>Customizable access based on user roles. For example: program manager, report admin.
    </li>
    <li>Super Admins can edit and create dashboards.</li>
    </ul>
    </td>
</tr>

<tr>
    <td>Customizable Dashboards</td>
    <td>
    <ul>
    <li>Dashboards can be tailored to meet specific needs. For example: adding block or cluster-level data.
    </li>
    <li>Editable via Metabase’s UI without coding.</li>
    </ul>
    </td>
</tr>


</table>
