# Observations without Rubrics

Observations can be done with or without rubrics. An observation without a rubric is similar to a survey process.
This uses simple forms for collecting data without any predefined set of criteria or standards.

For example:

* Class observation for a class/teacher in a school by the CRPs for all schools in a cluster on a weekly basis.
* An observation of the daily processes and functioning of the school by a block education officer.
* Observation of mid-day meal process in a school by the head master.
