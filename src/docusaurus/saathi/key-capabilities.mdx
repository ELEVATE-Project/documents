# Key Features of Saathi



<table>
<tr>
    <th>Features</th>
    <th>Description</th>
</tr>
<tr>
    <td>Clarity for Context</td>
    <td>Saathi helps users move beyond surface-level concerns to identify the
specific challenge that is most actionable. While balancing this with minimal questioning to
not fatigue the user.</td>
</tr>
<tr>
    <td>Actionable microimprovements</td>
    <td>Converts reflection into concrete next steps,
helping users develop micro improvement plans that are focused, practical, and
implementable.
 </td>
</tr>
<tr>
    <td>Continuous learning through conversation</td>
    <td>Serves as a coach for concepts,
processes, and practices, enabling users to learn interactively while solving real problems.
This further helps implement the micro improvements on ground. </td>
</tr>
<tr>
    <td>Proactive nudging for implementation support and follow ups</td>
    <td>Nudge users continuously post-generation of the improvement plan to ensure timely completion and proactively offer support when needed.</td>
</tr>

<tr>
    <td>Continuous cycle of improvement</td>
    <td>Saathi can use prior context from earlier conversations
or generated improvements to help users build on a previously identified challenge or similar
challenges that peers might have faced.
</td>
</tr>

</table>
